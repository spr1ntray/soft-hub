# Сначала откройте этот файл

## Актуальный релиз — 0.6.15

- **[Скачать Soft Hub для Windows 10/11 x64](https://github.com/spr1ntray/soft-hub/releases/download/v0.6.15/Soft-Hub-0.6.15-x64.exe)**
- **[Скачать Soft Hub для Mac с Apple Silicon](https://github.com/spr1ntray/soft-hub/releases/download/v0.6.15/Soft-Hub-0.6.15-arm64.dmg)**

В публичном репозитории эта папка содержит только инструкцию: крупные файлы опубликованной версии находятся в [GitHub Releases → Assets](https://github.com/spr1ntray/soft-hub/releases/tag/v0.6.15).

## Что находится в релизе

В этой рабочей папке после локальной сборки лежат:

- `Soft-Hub-0.6.15-arm64.dmg` — для Mac с Apple Silicon (M1/M2/M3/M4 и новее);
- `Soft-Hub-0.6.15-x64.exe` — для Windows 10/11 x64;
- `SHA256SUMS` — контрольные суммы файлов релиза.

Python, Node.js, Git, терминал и отдельную базу устанавливать не нужно — всё необходимое уже находится внутри Soft Hub.

Свежий Hub открывается без готовых софтов. При каждом запуске он сначала попросит создать или ввести мастер-пароль и только после этого покажет рабочий интерфейс. Добавьте нужные пакеты с компьютера, по ссылке на GitHub Release или через Patch Radar.

## Если ставите Hub впервые

На Mac откройте DMG и перетащите **Soft Hub** в **Applications**. На Windows запустите EXE и пройдите обычную установку.

## Если обновляете старую версию

### Опубликованное обновление

Обычно достаточно открыть **Настройки → Обновление Hub**. Hub сам проверит публичный репозиторий, покажет новую версию и только после вашего согласия скачает установщик и сверит его SHA-256.

1. Дождитесь завершения активных софтов. Ошибочные и отменённые запуски обновлению не мешают: их журнал и результаты останутся в истории.
2. Разрешите загрузку новой версии и дождитесь сообщения, что файл проверен.
3. Нажмите **Открыть установщик**. Hub заблокирует Vault и закроется, а затем:
   - на Mac откроется DMG — перетащите новую **Soft Hub.app** в **Applications** и выберите **Заменить**;
   - на Windows запустится NSIS EXE — пройдите установщик, не меняя папку установки.
4. Откройте Hub и проверьте номер версии в нижнем левом углу или в **Настройки → Обновление Hub**.

Если встроенная проверка GitHub временно недоступна, выполните те же шаги вручную с файлами из GitHub Releases и обязательно сверьте checksum-файл из того же Release.

Версия 0.6.12 на некоторых Windows-компьютерах не могла подключиться к GitHub и поэтому не видела собственное обновление. В таком случае один раз скачайте актуальный `Soft-Hub-0.6.15-x64.exe` вручную из Releases и установите поверх текущей версии. Начиная с 0.6.13 приложение содержит исправленный сетевой runtime.

Vault, аккаунты, установленные софты, история запусков и результаты хранятся отдельно от приложения и останутся на месте. Не удаляйте каталог пользовательских данных вручную.

Если после обновления рядом с каким-то софтом появилась кнопка **Подготовить**, нажмите её один раз. Это пересоберёт окружение под новый встроенный Python, но не удалит данные софта.

Текущие установщики не имеют публичной Apple/Windows-подписи. Получайте их только из официального GitHub Release и сверяйте с `SHA256SUMS` из того же релиза.
